# ONG Esperança

## Apresentação do projeto

O projeto consiste em um site para a ONG Esperança, com o objetivo de apresentar a organização, seus projetos, campanhas e possibilitar o cadastro de voluntários.

## Tecnologias utilizadas

- HTML5
- CSS3
- JavaScript
- Git

## Estrutura do projeto

O projeto possui páginas HTML, arquivos CSS, scripts JavaScript e imagens utilizadas no site.

Principais arquivos:

- `index.html` - página inicial
- `projetos.html` - página de projetos
- `cadastro.html` - formulário de cadastro
- `css/style.css` - estilos do projeto
- `js/` - arquivos JavaScript
- `imagens/` - imagens utilizadas no site

## Instalação

Para executar o projeto localmente:

1. Baixe ou clone o repositório.
2. Abra a pasta `projeto-ong`.
3. Abra a pasta no Visual Studio Code.
4. Verifique se os arquivos HTML, CSS e JavaScript estão presentes.
5. Abra o arquivo `index.html` no navegador.

## Execução

O projeto pode ser executado diretamente pelo navegador através do arquivo `index.html`.

As páginas possuem navegação entre si e utilizam CSS e JavaScript para estilização e funcionalidades.

## Versionamento

O projeto utiliza Git para controle de versões.

Foram utilizadas as branches:

- `main` - versão principal e estável do projeto.
- `develop` - branch destinada ao desenvolvimento.
- `feature/componentes-feedback` - branch utilizada para desenvolver os componentes de feedback.

Também foi utilizado o padrão de mensagens de commit baseado em Conventional Commits e versionamento semântico.

A primeira versão estável foi identificada como `v1.0.0`.

## Componentes de feedback

O projeto possui componentes visuais para apresentar informações ao usuário:

- Badge
- Alerta
- Toast
